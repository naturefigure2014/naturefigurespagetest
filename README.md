# NATURE FIGURE Astro

Astroで構築する「ネイチャーフィギュアのページ」の静的サイトです。

## 今回の変更（FIGURE画像）
- FIGURE詳細ページで、複数画像を含む話題は「画像2/3・説明1/3」のレイアウト。
- 話題内の画像をクリックすると拡大表示するライトボックスを表示。
- 拡大表示は元画像の縦横比を維持し、PC・スマートフォンの両方に対応。
- 背景クリック、閉じるボタン、Escキーで閉じられます。
- 既存の画像ファイル名をそのまま利用する方式は維持しています。

## 起動
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```
